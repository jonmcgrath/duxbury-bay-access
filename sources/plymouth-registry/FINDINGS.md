# Findings: Plymouth County Registry of Deeds (searched 2026-11-09)

Goal: find the recorded survey of each town landing. Bylaw Art. 300 §302 defines a town landing as "surveyed and recorded with the Plymouth County Registry of Deeds to the low water mark (mean)".

- **No entry mentions a "landing"** anywhere in the 1890–1966 index. The landing surveys were probably recorded after 1966. *Assumed.*

## 2. TitleView online index (https://titleview.org/plymouthdeeds/)
- Searching and viewing are free; printing requires a paid subscription.
- A name search for "DUXBURY TOWN OF" with no filters times out because there are too many records. Use Advanced → Town = DUXBURY plus document types.
- **Takings** (Town = Duxbury): almost all are tax takings ("by collector"), from 1945 on. Not relevant.
- **Votes / certificates / easements / dedications / licenses**: about 1,000 rows (the cap). The index has **no description or street** for these, so the landing records can't be picked out without opening each document.
- **The image viewer did not open** through the browser extension (2 attempts on 2026-11-09, document VOTE Book 1949 p. 131, 1/10/1947).
